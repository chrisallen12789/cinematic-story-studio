# Phase 3B.1 known limitations

Phase 3B.1 is a restricted private-audition bridge, not a production speech
release. These boundaries remain deliberate:

- The exact allow-listed package contains one technically compatible voice
  tensor. Six distinct real candidates are unavailable; the private automated
  package therefore uses the one governed profile for two narrator purposes
  and four character purposes and records that limitation.
- The voice-tensor license scope, complete dataset provenance, performer
  consent, identity and likeness clearance, commercial clearance,
  redistribution rights, and sublicensing rights remain incomplete or
  unknown. An acknowledgement does not resolve them.
- Automated WAV, duration, hash, non-silence, clipping, cache, and process
  checks do not establish intelligibility, naturalness, expression, listener
  comfort, long-form suitability, or artistic quality.
- Human listening is mandatory and remains pending until the repository owner
  listens to the exact private clips and records current exact-clip
  dispositions. CI cannot perform or claim that decision.
- Hosted CI contains no real model, tensor, or generated real-provider audio.
  It proves fixture lifecycle behavior, synthetic governed metadata, and
  absent-package fail-closed behavior only.
- Python socket denial and owned-PID endpoint inventory are scoped safeguards;
  they are not a complete OS firewall or packet capture.
- The product supports bounded short auditions only. It does not implement
  automatic chunking, silent truncation, full-book or chapter rendering,
  performance direction, mixing, mastering, music, ambience, Foley, MP3/M4B,
  or production export.
- Only one Windows x64 CPU execution profile is allow-listed. There is no
  automatic model download, arbitrary model selection, GPU profile, cloud
  provider, user voice upload, cloning, or real-person enrollment.
- A catalog, rights, package, assignment, cast-snapshot, pronunciation, clip,
  artifact, or approval change invalidates the dependent authority. The user
  must regenerate and re-review current evidence; old approval is never
  silently restored.
- The generated listening package is intentionally private, ignored, and
  local. Its separately ignored desktop-state sibling is retained only so the
  exact authenticated clips can be replayed after automated shutdown; it may
  contain a synthetic-project database, model installation, audio, and caches.
  Neither directory is committed or uploaded, and loss of either requires a
  new exact product-path run.

Phase 3C and Phase 4 have not started. Production readiness, public release,
signing, updates, marketplace distribution, and legal clearance remain out of
scope.
